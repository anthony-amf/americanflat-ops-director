# skill-shorts-processing

Process daily AMF warehouse short orders into a routed Short Report, Slack post, and warehouse action emails.

See `SKILL.md` for full operator instructions and routing rules.

## Files

- `SKILL.md` — main skill instructions
- `reference/email-template.md` — warehouse action email template
- `reference/slack-post-template.md` — Slack post template (includes the always-on cc rule)
- `reference/warehouse-priorities.md` — US warehouse priority order
- `reference/sku-alternates.csv` — bidirectional SKU substitution mapping (1,444 pairs)
- `examples/sample-output.md` — worked example showing all four deliverables
